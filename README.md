# 時間割共有サービス

2-1〜2-9のクラスごとに時間割を共有・編集できるWebアプリです。
Node.js + Express + PostgreSQL(Render)で動作します。

## 仕組み(A週・B週 + 日々の授業変更)

実際に表示される時間割は、以下の2つを重ね合わせて計算されます。

1. **基本パターン(A週・B週)**:クラスごとに2種類の雛形(月〜土)。年に数回しか変わらない想定で、admin(管理者)だけが編集します。「基本パターン設定」ページで設定します
2. **週タイプ設定**:どの週がA週かB週かをカレンダー上で設定します(不規則な学校の運用に対応するため、自動計算ではなく手動設定)。「週タイプ設定」ページで、その週のどこか1日の日付を選んで設定します
3. **日々の授業変更**:特定の日付だけの上書き。毎日の運用で編集していく部分で、クラス別ページ・全クラス表示ページの両方から、当日以降の好きな日付を選んで入力できます

表示時は「その日が属する週の基本パターン」+「その日の授業変更」がマージされ、変更がある時限は黄色くハイライトされます。

## 権限モデル

- `admin`: 全クラスの閲覧・編集、基本パターン・週タイプ・ユーザー管理が可能
- `editor`: 割り当てられたクラスのみ、日々の授業変更を編集可能(基本パターンは編集不可)
- `viewer`: 割り当てられたクラスのみ閲覧可能

「全クラス表示」ページ(旧・今日の時間割)は全員が見られますが、そこでの編集はadminのみです。

## ローカルでの動作確認

1. Node.js(18以上推奨)をインストール
2. 依存パッケージをインストール
   ```
   npm install
   ```
3. `.env.example` をコピーして `.env` を作成し、値を編集
   ```
   cp .env.example .env
   ```
   `DATABASE_URL` はローカルのPostgreSQL、またはRenderのPostgreSQLの接続文字列を指定します。
4. データベースを初期化(テーブル作成+管理者アカウント作成)
   ```
   npm run init-db
   ```
   `ADMIN_USERNAME` / `ADMIN_PASSWORD` で指定した管理者アカウントが作成されます。
5. サーバーを起動
   ```
   npm start
   ```
6. ブラウザで `http://localhost:3000` を開き、管理者アカウントでログイン
7. 初回は以下の順で設定してください
   - 「基本パターン設定」でクラスごとにA週・B週の雛形を入力
   - 「週タイプ設定」で今週以降のA週/B週を設定
   - これで「全クラス表示」やクラス別ページに反映されます

## Renderへのデプロイ手順

### 方法A: render.yaml を使う(おすすめ・自動)

1. このフォルダの中身をGitHubリポジトリにpush
2. Renderにログイン → 「New +」→「Blueprint」
3. リポジトリを選択すると `render.yaml` が自動検出され、
   Webサービスとデータベースがまとめて作成される
4. `ADMIN_PASSWORD` を要求されるので、初期管理者パスワードを入力
5. デプロイ完了後、Web ServiceのSettingsで Start Command を
   ```
   npm run init-db && npm start
   ```
   に変更して保存する(無料プランはShellが使えないため、起動時に自動で初期化する方式にしています。init-dbは既にあるデータには影響しないため、毎回実行しても安全です)

### 方法B: 手動で作成する

1. Renderで「New +」→「PostgreSQL」を作成し、`Internal Database URL` を控える
2. 「New +」→「Web Service」を作成し、このリポジトリを接続
   - Build Command: `npm install`
   - Start Command: `npm run init-db && npm start`
3. 環境変数(Environment)に以下を設定
   - `DATABASE_URL`: 手順1で控えた接続文字列
   - `PGSSL`: `true`
   - `SESSION_SECRET`: 適当なランダム文字列
   - `ADMIN_USERNAME`: 任意の管理者ID
   - `ADMIN_PASSWORD`: 任意の初期パスワード

## 運用の流れ

1. 管理者アカウントでログイン
2. 「基本パターン設定」でA週・B週の雛形を入力(年度替わりや時間割変更のときだけ)
3. 「週タイプ設定」で各週がA週かB週かを設定(不規則な週があれば個別に調整)
4. 「ユーザー管理」画面で、担当者(editor)・閲覧者(viewer)のアカウントを作成
   - 1人に複数クラスを割り当て可能
   - 閲覧者は共有アカウント1つでも構いません
5. 各担当者は自分のアカウントでログインし、担当クラスの「日々の授業変更」を入力
6. 閲覧者・生徒は「全クラス表示」やクラス別ページで、その日の実際の時間割(基本+変更)を閲覧

## セキュリティ上の注意

- 初期パスワードは必ず個別に伝え、使い回さないようにしてください
- 本番運用では `SESSION_SECRET` を推測されにくい値にしてください
- 必要に応じて、ユーザーが自分でパスワードを変更できる機能を追加することをおすすめします(現状は管理者のみが再設定可能)
